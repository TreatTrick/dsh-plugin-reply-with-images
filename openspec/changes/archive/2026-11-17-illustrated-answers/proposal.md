## Why

当前插件的自动配图提示仅覆盖外观、地点、物体、自然和视觉比较。面对人物介绍或新闻事件长答时，模型可能完全不调用图片工具；即使决定配图，也需要分别搜索、选图和保存，步骤多且容易被省略。

本次将“适合配图时更稳定地得到图片”和“图片能在正文中易读地展示”作为完整目标，同时保留用户要求纯文字、图源不可用或保存失败时的文字回答能力。

## What Changes

- 扩展自动配图判断，覆盖人物及机构介绍、新闻与事件、旅游地点、商品和视觉比较；短答、抽象主题及纯文字要求仍跳过配图。
- 增加一次调用即可按主题搜索并保存图片的工作流，返回可直接插入正文的 Markdown 和逐图失败说明；保留现有分步工具供精确选图使用。
- 为长答规定图片规划与插入方式：将单张图片放在对应说明之后；人物索引或多图比较可使用含图 Markdown 表格，以免图片与主题脱节。
- 提供可选 DSH Web 客户端样式，将含图 Markdown 表格呈现为紧凑的图文行或图片组；无该客户端、无图片或图片加载失败时，原始文字及标准 Markdown 仍可读。
- 扩充默认配图预算，并保留来源、作者和许可说明；自动配图仍受用户配置和安全检索限制约束。

### New Capabilities

- `illustrated-answers`: 自动规划、获取并组织回答配图，同时在失败或用户不需要图片时优雅退回文字。

## Impact

- Host：`src/index.ts`、`src/config.ts`、`src/tools.ts`、`src/replyImages.ts` 和图片工作流测试。
- Optional Web client：新增浏览器入口与客户端样式，并更新 `package.json` 的 DSH 客户端清单、导出和构建配置。
- 用户文档及本地预览：说明新工作流的行为、预算、回退条件和客户端限制。
- 不修改 DSH Harness 仓库；不添加运行时依赖；现有图片工具和持久化图片 Markdown 保持兼容。
