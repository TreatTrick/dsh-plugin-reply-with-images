## ADDED Requirements

### Requirement: 自动识别适合插图的回答

当 automatic 配置开启时，系统提示 MUST 明确要求模型考虑在较长的人物、组织、新闻或事件、商品、地点、自然主题和视觉比较回答中插入相关实图，并说明应将图放到相关说明之后。短答、代码、抽象主题和纯文字请求 MUST 被指导为不搜索图片。配置关闭时 MUST 继续只在用户明确请求图片时使用图片工具。

#### Scenario: 长篇人物和事件综述

- **WHEN** 用户要求详细介绍一位公众人物和相关事件，且 automatic 已开启
- **THEN** 模型收到明确的配图要求，并能在该轮看到单次图片准备工具

#### Scenario: 纯文字、短答或抽象主题

- **WHEN** 用户要求短答、纯文字回答，或咨询代码及抽象概念
- **THEN** 模型收到跳过装饰性配图的指导

#### Scenario: 用户关闭自动配图

- **WHEN** automatic 已关闭且用户没有要求图片
- **THEN** 系统提示禁止主动调用自动和分步图片工具

### Requirement: 单次调用准备主题配图

系统 MUST 提供 `reply_images_prepare`，让模型一次提交有序主题、简洁搜索词和 alt 文本，并返回可直接插入答案的图片 Markdown、来源与许可信息及逐项警告。工具 MUST 按单轮剩余搜索和图片预算限制主题数量，沿用现有安全 Provider 和持久化附件能力，并处理取消及插件卸载。每个主题成功或失败 MUST 独立报告，不得因一个主题失败丢失其他已成功图片。原有 `reply_image_search` 和 `reply_images_embed` MUST 继续可用。

#### Scenario: 长答一次准备多张图片

- **WHEN** 模型提交多个合法且未超过当前剩余预算的主题
- **THEN** 单次工具调用按序搜索和保存各主题的首个可用候选，并为每张成功图片返回含来源和许可说明的 Markdown

#### Scenario: 主题超过剩余预算

- **WHEN** 提交的主题数超过搜索预算或图片预算
- **THEN** 工具拒绝超额输入且不得在网络或附件服务上执行超额工作

#### Scenario: 部分图源失败

- **WHEN** 一项搜索无结果或一张图片下载保存失败而其他主题成功
- **THEN** 工具保留成功图片并对失败主题返回可读警告

#### Scenario: 插件卸载或请求取消

- **WHEN** 图片准备期间当前轮取消或插件开始卸载
- **THEN** 网络工作停止并按现有附件写入排空契约结束

### Requirement: 图片分组可读且有来源说明

当回答需要紧凑的人物/实体目录或多图对比时，自动配图指导 MUST 允许使用标准 Markdown 含图表格；普通单图仍 MUST 可以嵌入相关段落之后。每张图片 MUST 保留准确 alt 文本以及由工具返回的来源和许可信息，不得将未知许可描述为可再发布许可，也不得将未经核实的图片描述为所涉人物或不当行为的证据。

#### Scenario: 人物目录与并列图片组

- **WHEN** 模型创建人物目录或视觉对比并将图片放入标准 Markdown 表格
- **THEN** 每个图片组在原 Markdown 中仍与相邻的名称、说明和来源对应

#### Scenario: 普通单图插入回答

- **WHEN** 一个主题的图片适合配合独立段落
- **THEN** 模型可以直接插入该图的 Markdown 及其来源和许可说明，无须创建表格

#### Scenario: 结果未能验证图片身份或许可证

- **WHEN** Provider 仅返回标题和来源，或许可状态未知
- **THEN** 输出不得声称已检查图片内容或存在再发布许可，并继续显示现有的许可证状态文字

### Requirement: 客户端图片表格与查看器增强

启用插件 Web 客户端入口时，DSH MUST 将仅包含普通 Markdown 的图片表格呈现为响应式图文行或等宽比较组，并允许通过鼠标和键盘放大单张普通 Markdown 图片。查看器 MUST 限制图片在可视视口内，展示图片 alt，支持 Escape 和明确的关闭按钮。图片加载失败 MUST 保留 Markdown renderer 的可读错误/alt 回退。未加载客户端入口时，原回答 MUST 仍以普通 Markdown 图片和表格展示。

#### Scenario: 桌面视口展示人物表格

- **WHEN** Web 客户端已加载且回答包含首列带图的人物目录表格
- **THEN** 图片以紧凑栏呈现，人物文字与来源在邻列保留

#### Scenario: 窄屏展示多图对比

- **WHEN** Web 客户端已加载且宽度受限的视口显示多列图像比较
- **THEN** 图片尺寸限制在各自列内，主题说明不得与相邻列重叠

#### Scenario: 鼠标或键盘放大查看

- **WHEN** 用户激活一张普通 Markdown 图片
- **THEN** 图片在键盘可关闭、含替代文字的视口查看器中放大，Escape 或关闭操作返回回答

#### Scenario: 图片加载失败或客户端未启用

- **WHEN** 图片 URL 不可用或 DSH 客户端增强未加载
- **THEN** 图片错误仍由 Markdown 回退处理，正文、表格与来源不会因增强缺失而丢失

### Requirement: 默认预算与逐图回退

系统 MUST 将默认每轮图片搜索和图片预算都设为三，并继续接受用户有效的每轮预算覆写。无结果、预算不足和逐图存储错误 MUST 允许模型完成有用的文字回答，并提供说明失败原因的工具结果。

#### Scenario: 默认单次配图预算

- **WHEN** 插件以默认配置加载
- **THEN** 模型单轮最多准备三项图片主题且保存显示图片总数不超过三

#### Scenario: 用户自定义较小预算

- **WHEN** 配置将单轮图片或搜索预算下调
- **THEN** 工具和模型提示均遵从较小配置值

#### Scenario: 全部图源不可用

- **WHEN** 所有当前 Provider 均失败或找不到可用候选
- **THEN** 工具返回有界警告，模型能够继续提交无图文本回答
